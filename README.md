# javascript-lotto-precourse

## 우아한 테크코스 1주차 프리코스

## 🎫 로또 - Lotto

간단한 로또 발매기 구현 프로그램입니다.

사용자는 로또 구입 금액을 입력하고, 프로그램은 해당 금액만큼 로또를 자동 발행합니다.

이후 당첨 번호와 보너스 번호를 입력받아 당첨 내역과 수익률을 출력합니다.

---

## 🚀 실행 방법

```bash
npm install

npm run start
```

---

## 🧩 구현할 기능 목록

### 1️⃣ 구입 금액 입력 및 검증

- [ ]  사용자가 로또 구입 금액을 입력한다.
- [ ]  구입 금액이 1,000원 단위인지 검증한다.
- [ ]  잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 다시 입력받는다.

### 2️⃣ 로또 발행

- [ ]  구입 금액에 따라 로또 개수를 계산한다.
- [ ]  각 로또는 1~45 범위의 중복되지 않은 6개의 숫자로 구성된다.
- [ ]  발행된 로또 번호를 오름차순으로 정렬해 출력한다.

### 3️⃣ 당첨 번호 입력 및 검증

- [ ]  당첨 번호 6개를 입력받는다.
- [ ]  1~45 범위이고, 중복 없음을 검증한다
- [ ]  잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 다시 입력받는다.

### 4️⃣ 보너스 번호 입력 및 검증

- [ ]  보너스 번호를 입력받는다.
- [ ]  1~45 범위 내 숫자인지 검증한다.
- [ ]  당첨 번호와 중복되지 않는지 검증한다.
- [ ]  잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 다시 입력받는다.

### 5️⃣ 당첨 결과 계산

- [ ]  사용자가 구매한 모든 로또를 당첨 번호와 비교한다.
- [ ]  일치 개수에 따라 등수를 판별한다.
    - 6개 일치 → 1등 (2,000,000,000원)
    - 5개 + 보너스 일치 → 2등 (30,000,000원)
    - 5개 일치 → 3등 (1,500,000원)
    - 4개 일치 → 4등 (50,000원)
    - 3개 일치 → 5등 (5,000원)
- [ ]  각 등수별 당첨 개수를 집계한다.

### 6️⃣ 수익률 계산 및 출력

- [ ]  총 상금 합계를 계산한다.
- [ ]  수익률을 `총 당첨금 / 구입 금액 * 100`으로 계산한다.
- [ ]  소수점 둘째 자리에서 반올림한다.
- [ ]  예시: `총 수익률은 62.5%입니다.`

### 7️⃣ 예외 처리 공통 규칙

- [ ]  모든 입력값은 잘못되었을 경우 예외(`Error`)를 발생시킨다.
- [ ]  에러 메시지는 반드시 `[ERROR]`로 시작해야 한다.
- [ ]  예외 발생 시 해당 지점부터 다시 입력받는다.
